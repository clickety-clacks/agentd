# Agentd 0.3.4

Agentd 0.3.4 includes `agentd-attention`, an optional local bridge. Core Agentd list and watch remain independent of the bridge; the optional program is not installed or enabled by Agentd's standard installation flow.

Run `agentd-attention` in the foreground when Agentd and the local Attention daemon are available. The packaged invocation guide is `docs/agentd-attention.md`; the archive also contains an optional service unit for downstream use.

The bridge consumes Agentd's local JSON watch stream and posts `needs_attention` metadata to the local Attention daemon over a Unix socket. It sends no message body, does not inspect prompts, pane contents, terminal output, or transcripts, and accepts no remote endpoint or socket override.

The bridge was tested against Scottland Attention 0.3 built from source over a local socket. The test supplied controlled Agentd snapshots; it was not an end-to-end test with a live Agentd roster. It was not tested against an installed Scottland package across login or reboot.
