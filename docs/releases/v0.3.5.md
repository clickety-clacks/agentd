# Agentd 0.3.5

Agentd 0.3.5 fixes process discovery and hook ancestry when PID 1 reports a
start time of zero. An unreadable PID 1 now ends the ancestry walk, allowing the
roster to include agent processes and hooks to resolve their agent root.

Other unreadable or missing ancestors remain unresolved, and a zero start time
remains invalid as a process identity. The local socket and JSON watch protocol
are unchanged.
